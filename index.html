Privacy Policy — Ticket Watch for Discord

Last updated: September 4, 2026

Ticket Watch for Discord ("the extension") is a browser extension built for internal use by a small team to track ticket-channel activity on Discord. This policy explains what data the extension accesses, how it is used, and how it is stored.

What the extension does

The extension runs on discord.com/channels/* pages. It reads channel names and timestamps visible on the page to detect when new ticket channels are created, lets a user set a short status message, and calculates daily/weekly ticket counts from that data.

What data is collected

  • Website content: Channel names and creation timestamps read from Discord pages the user is viewing, used solely to detect and log ticket activity.
  • User-provided status text: A short status string the user types themselves (e.g. "Handling tickets").
  • Notes: Any text a user types into the shared notes field for a ticket.

The extension does not collect passwords, private messages, direct message content, financial information, health information, or precise location data. It does not use tracking pixels, analytics SDKs, or advertising identifiers.

How data is stored

Data is stored in two places:

  • Local browser storage (via the extension's storage permission), for data specific to the current user's browser.
  • A private Supabase backend operated for this team, used so ticket timestamps and status are visible to teammates using the extension. This backend is not publicly accessible and is not shared with any third party outside the team.

How data is used

Collected data is used only to power the extension's single purpose: showing when tickets were created, letting teammates see each other's status, and displaying ticket count summaries. It is not sold, rented, or shared with advertisers or data brokers, and it is not used for any purpose unrelated to this functionality.

Data retention and deletion

Ticket and status data is retained for as long as needed to provide the daily/weekly summaries. A user can clear their locally stored data by removing the extension or clearing extension storage in their browser. To request deletion of data held in the team's Supabase backend, contact the extension maintainer using the details below.

Third parties

The only third-party service used is Supabase, which hosts the backend database for this team. No other third-party services receive data collected by this extension.

Changes to this policy

If how the extension handles data changes, this page will be updated and the "Last updated" date above will change accordingly.
